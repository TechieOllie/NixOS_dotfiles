# home/umbriel/

Umbriel's user config, ported from [`home/niri/`](../niri/) for hosts on
`features.umbriel`. [`home/umbriel.nix`](../umbriel.nix) links every file
here into `~/.config/umbriel/` as an out-of-store symlink into the host's
`~/.dotfiles` clone, so an edit applies on save without a rebuild. The same
rule as niri's KDL applies: edits in *this* working tree reach a host only
once pushed and pulled there (see [`docs/live-dotfiles.md`](../../docs/live-dotfiles.md)).

`config.toml` is the entry point and only includes the rest. Check a change
with `umbriel config validate`, which rejects unknown keys and actions
rather than ignoring them.

Three files in `~/.config/umbriel/` don't come from here:

- `cfg/input.toml`: generated by `home/umbriel.nix`, since the keyboard
  layout comes from `vars`.
- `style.toml`: generated by `home/noctalia.nix` from its `style` block
  (the corner radius).
- `noctalia.toml`: written at runtime by Noctalia's builtin `umbriel`
  template (colors).

## Added on top of the niri port

- **Scratchpads** (`cfg/scratchpad.toml`): a dropdown Lazygit
  in Ghostty (`Mod+Shift+Return`), Feishin (`Mod+M`) and Vesktop
  (`Mod+D`). The first press launches the app if it isn't running, and later presses show and
  hide it. Vesktop autostarts, so it is already waiting, hidden, after login.
- **Game rules** (`cfg/rules.toml`): pointer confinement and adaptive sync
  for Proton games and for any window that declares itself a game.
- **The cursor hides while typing** (`cfg/misc.toml`).
- **The replay buffer** works here too (`Alt+F10`, `Alt+Shift+F10`).
  `home/gpu-screen-recorder.nix` reads `umbriel subscribe windows` instead
  of niri's event stream.

## AZERTY and keybinds

Umbriel matches a bind against the key's **unshifted** symbol in the
active layout, and only borrows another layout's symbol when several are
configured. This config has only `fr`, so the number row is bound by what it
types without Shift (`ampersand`, `eacute`, `quotedbl`, `apostrophe`,
`parenleft`, `minus`, `egrave`, `underscore`, `ccedilla`), and `minus` is
the 6 key. A bind written as `Mod+1` is accepted by `umbriel config validate`
and never fires. The column-width keys moved to `parenright`/`equal`, the
two keys left of Backspace, because `minus` is workspace 6.

## What didn't carry over from niri

- **`center-visible-columns`** (`Mod+Ctrl+C`): no equivalent action. Unbound.
- **`hotkey-overlay-title`** strings: Umbriel's cheatsheet lists binds
  without titles.
- **`draw-border-with-background false`**: niri-only. Umbriel draws no
  solid backing behind windows.
- **The `noctalia-wallpaper` `place-within-backdrop` layer rule**: niri-only.
  Umbriel's overview draws the wallpaper itself.
- **Vesktop's `open-on-output`**: it named the desktop's second monitor.
- **niri's `debug { honor-xdg-activation-with-invalid-serial }`**: no
  equivalent. If Noctalia's notification actions stop focusing windows, look
  at `general.focus_on_activate` first.
- **`clipboard { disable-primary }`**: no equivalent option.
- **Separate springs for view movement, window movement and resize**
  (800/900/1000): Umbriel has one `windows_move` event, set to 900.
- **Animations for the config notification and the screenshot UI**: Umbriel
  has neither.

Display layout (niri's `cfg/display.kdl`) isn't ported wholesale; only the
outputs that need settings are, at the end of `cfg/layout.toml`: theseus's
panel by connector (`eDP-1`), and the desktop's Samsung by monitor
identity, since theseus's USB-C outputs share the desktop's `DP-n` names.
They sit there rather than in a `cfg/display.toml` of their own: a new include needs a Home Manager switch to create its symlink,
while a live file already in place takes effect on save.
