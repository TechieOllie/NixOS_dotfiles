# home/umbriel/

Umbriel's user config, ported from [`home/niri/`](../niri/) for hosts on
`features.umbriel`. [`home/umbriel.nix`](../umbriel.nix) links every file
here into `~/.config/umbriel/` as an out-of-store symlink into the host's
`~/.dotfiles` clone, so an edit applies on save without a rebuild. The same
rule as niri's KDL applies: edits in *this* working tree reach a host only
once pushed and pulled there (see [`docs/live-dotfiles.md`](../../docs/live-dotfiles.md)).

`config.toml` is the entry point and only includes the rest. Check a change
with `umbriel config validate`, which rejects unknown keys and actions
rather than ignoring them.

Three files in `~/.config/umbriel/` don't come from here:

- `cfg/input.toml`: generated by `home/umbriel.nix`, since the keyboard
  layout comes from `vars`.
- `style.toml`: generated by `home/noctalia.nix` from its `style` block
  (the corner radius).
- `noctalia.toml`: written at runtime by Noctalia's builtin `umbriel`
  template (colors).

## What didn't carry over from niri

- **`center-visible-columns`** (`Mod+Ctrl+C`): no equivalent action. Unbound.
- **`hotkey-overlay-title`** strings: Umbriel's cheatsheet lists binds
  without titles.
- **`draw-border-with-background false`**: niri-only. Umbriel draws no
  solid backing behind windows.
- **The `noctalia-wallpaper` `place-within-backdrop` layer rule**: niri-only.
  Umbriel's overview draws the wallpaper itself.
- **Vesktop's `open-on-output`**: it named the desktop's second monitor.
- **niri's `debug { honor-xdg-activation-with-invalid-serial }`**: no
  equivalent. If Noctalia's notification actions stop focusing windows, look
  at `general.focus_on_activate` first.
- **`clipboard { disable-primary }`**: no equivalent option.
- **Separate springs for view movement, window movement and resize**
  (800/900/1000): Umbriel has one `windows_move` event, set to 900.
- **Animations for the config notification and the screenshot UI**: Umbriel
  has neither.
- **The replay buffer binds** (`Alt+F10`, `Alt+Shift+F10`): `home/gpu-screen-recorder.nix`
  follows `niri msg --json event-stream` to start the buffer with games, so
  it stays gated on `features.niri`. Porting it means rewriting that watcher
  against `umbriel subscribe windows`.

Display layout (niri's `cfg/display.kdl`) isn't ported. It described the
desktop's two monitors, and a laptop's single panel needs no `[output]`
table until its scale has been checked on the real screen.
